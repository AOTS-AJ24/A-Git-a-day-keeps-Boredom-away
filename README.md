# A-Git-a-day-keeps-Boredom-away
Just Small code I feel to upload 

A growing collection of small Java programs that solve daily coding challenges, basic DSA problems, logical tasks, and beginner-friendly algorithms.
This repository is designed as a daily practice space — where each folder contains a set of solved problems, clean code, and simple explanations to help improve problem-solving and Java fundamentals.
